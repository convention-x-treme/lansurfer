# Third-party notices for the UI-kit snapshots

This file documents the **self-contained, archived Claude Design HTML exports** at `docs/ui-kit/index.html` and `docs/ui-kit/LANsurfer Colour Palette.html`, reviewed 2026-10-16. It is **not** an inventory of the LANsurfer production application or its released binaries/images; their dependencies are tracked separately in [the root notices](../../THIRD_PARTY_NOTICES.md).

The exports contain embedded resources in `__bundler/manifest`, not merely external links:

| Resource | License | Where embedded |
| --- | --- | --- |
| React 18.3.1 and ReactDOM 18.3.1 (UMD bundles) | MIT | Both HTML exports, compressed JavaScript resources, originally referenced from `unpkg.com` |
| JetBrains Mono WOFF2 fonts | SIL OFL 1.1 | Both exports |
| Montserrat WOFF2 fonts | SIL OFL 1.1 | Older `index.html` UI snapshot |
| Schibsted Grotesk WOFF2 fonts | SIL OFL 1.1 | `LANsurfer Colour Palette.html` |

The manifests also contain generated Claude Design page/runtime code and one image in `index.html`. Those generated resources are **not automatically licensed as React, MIT or OFL**. The owner reports the original UI artwork was produced using Claude; rights and source details are tracked in [#92](https://github.com/convention-x-treme/lansurfer/issues/92) and [ASSETS-LICENSE.md](../../ASSETS-LICENSE.md). This audit did not independently identify every library potentially included in generated/minified page code, nor verify the exact build/revision of each embedded font subset. These are not production dependencies.

**If redistributing either standalone HTML export outside this repository, include this notices document and the license/copyright notices below alongside the file.** Do not infer that the code AGPL grants a trademark license or sublicenses fonts under AGPL.
