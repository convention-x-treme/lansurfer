## Alpine CA certificate bundle

The inspected release image contains Alpine `ca-certificates-bundle` `20260909-r0`. Its package metadata declares `MPL-2.0 AND MIT`. The package file list contains only certificate bundle files and compatibility symlinks. Alpine's source recipe says a GPL-2.0-or-later script is not shipped. The package's MIT-licensed `c_rehash.c` helper identifies copyright 2013–2014 Timo Teräs, but that helper is absent from the bundle package and final image.

Mozilla's source `certdata.txt` carries an MPL-2.0 notice. Mozilla's CA FAQ directs parties embedding its root store to the CCADB Data Usage Terms. Those terms license CCADB data under CDLA-Permissive 2.0 and require attribution to CCADB. The final image's certificate bundle is attributed to the Mozilla root store and CCADB; full applicable MPL and CDLA texts follow. These notices record source metadata, not legal advice or a separate clearance of every certificate.

Evidence: [Alpine package metadata](https://pkgs.alpinelinux.org/package/edge/main/x86/ca-certificates-bundle), [Alpine source recipe](https://gitlab.alpinelinux.org/alpine/aports/-/blob/a3c0689895e115d2910ab915de99a85bc11afe42/main/ca-certificates/APKBUILD), [bundle contents](https://pkgs.alpinelinux.org/contents?name=ca-certificates-bundle&repo=main&branch=edge&arch=x86), [Mozilla certificate source header](https://hg.mozilla.org/releases/mozilla-release/raw-file/default/security/nss/lib/ckfw/builtins/certdata.txt), [Mozilla bundler FAQ](https://wiki.mozilla.org/CA/FAQ), and [CCADB Data Usage Terms](https://www.ccadb.org/rootstores/usage#ccadb-data-usage-terms).
