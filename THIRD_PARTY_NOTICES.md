# Third-Party Notices

These are notices and license texts for third-party material bundled in LANsurfer's Go executable or embedded frontend assets. This inventory reflects `go.mod` and `package-lock.json` checked at `main` revision `95f929499333b00f0f8301c37af3f728861bbeec` on 2026-10-15; it is **not automatically updated** when dependencies change.

LANsurfer's own source license is in [`LICENSE`](LICENSE) (AGPL-3.0). Original LANsurfer trademarks, logo, mascots and other artwork are addressed separately in [`ASSETS-LICENSE.md`](ASSETS-LICENSE.md).

**Maintainer procedure:** When a shipped dependency or bundled asset changes, recheck `go.mod`, `package-lock.json`, the exact upstream license/NOTICE files and actual embedded outputs, then update this file as part of that dependency's PR/release preparation. Do not assume every npm development dependency is distributed, and do not infer license compatibility from a bare SPDX identifier. The Apache-2.0 license text is provided once below for all packages that use it; individual upstream `NOTICE` files are reproduced where present.
