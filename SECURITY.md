# Security Policy

LANsurfer is in early development and does not yet have a stable supported release. Security fixes are applied to the `main` branch.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's **Security** tab and choose **Report a vulnerability** to send the maintainers a private report. Include reproduction steps, affected versions or commits, impact, and any suggested mitigation. Remove credentials and personal data from logs or examples.

The maintainers will acknowledge the report, investigate it, and coordinate disclosure and a fix as appropriate. If private vulnerability reporting is not available, contact a repository maintainer privately before sharing details.
