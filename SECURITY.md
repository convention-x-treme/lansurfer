# Security Policy

## Supported versions

Security fixes land on the `main` branch and ship in the next release. Only the latest release line is supported.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability.

Use GitHub's **Security** tab and choose **Report a vulnerability** to send the maintainers a private report. Include reproduction steps, affected versions or commits, impact, and any suggested mitigation. Remove credentials and personal data from logs or examples.

The maintainers will acknowledge the report, investigate it, and coordinate disclosure and a fix as appropriate. If private vulnerability reporting is not available, email [opensource@convention-x-treme.de](mailto:opensource@convention-x-treme.de) before sharing details publicly.
